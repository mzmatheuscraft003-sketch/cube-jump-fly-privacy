# Política de Privacidade — Cube Jump Fly

Última atualização: 05 de novembro de 2026

A sua privacidade é importante para nós. É política do Cube Jump Fly respeitar a sua privacidade em relação a qualquer informação que possamos coletar no aplicativo.

### 1. Coleta e Uso de Dados
O jogo **Cube Jump Fly** não coleta, armazena ou transmite dados de identificação pessoal (como nome, e-mail, telefone ou endereço) em servidores próprios. 

O progresso do jogo, como moedas acumuladas, conquistas e melhorias compradas na loja do jogo, é salvo exclusivamente de forma local no seu dispositivo utilizando a tecnologia `localStorage`.

### 2. Serviços de Terceiros e Publicidade
O aplicativo utiliza serviços de terceiros que podem coletar informações usadas para identificar o seu dispositivo de forma anônima para a exibição de anúncios.

Utilizamos o **Google AdMob** para exibição de anúncios públicos e recompensados. O Google AdMob pode coletar e processar dados como:
- Identificadores de publicidade do dispositivo (ID de publicidade do Android).
- Dados de desempenho do anúncio e interações.
- Endereço IP aproximado para geolocalização e prevenção de fraudes.

Para saber mais sobre como o Google utiliza seus dados, acesse a Política de Privacidade do Google: https://policies.google.com/privacy

### 3. Sensores do Dispositivo
O aplicativo acessa os dados do giroscópio e acelerômetro do seu dispositivo unicamente para processar os comandos de movimento lateral do personagem durante a jogabilidade. Esses dados de movimento não são gravados nem transmitidos para nenhum servidor.

### 4. Privacidade de Crianças
O jogo é adequado para o público geral, mas não coleta intencionalmente dados pessoais de crianças.

### 5. Alterações a Esta Política
Podemos atualizar nossa Política de Privacidade periodicamente. Recomendamos que você revise esta página regularmente para verificar quaisquer alterações.

### 6. Contato
Se você tiver dúvidas sobre esta Política de Privacidade, entre em contato através do e-mail do desenvolvedor cadastrado na Ficha da Loja na Google Play Store.
